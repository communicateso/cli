# Changelog

## 0.1.5 — 2026-10-06

Install: `npm install -g @communicate_so/cli@0.1.5` (Node 22 or newer).

Account API keys can now drive much more of Communicate without the dashboard. Each command needs the matching scope on your key.

- **Inbox:** review and manage tickets, internal notes, labels, reply retry, attachments (upload, confirm, read), copilot suggestions, live support requests.
- **Contacts:** create, search and manage contact profiles.
- **Agents:** saved replies, automation rules, support settings and signatures, HTTP actions, help-center articles, agent grants, contacts, logo fetch, voice catalog, source page removal, preview chat.
- **Linked agents:** manage linked agents, work linked conversations, linked copilot and attachments, linked analytics.
- **Workspace:** labels, custom domains, webhooks, support request lifecycle and SLA commands.
- **Analytics and billing:** read agent, workspace and in-app analytics; read billing.
- **Account:** read and update account preferences.

Run `communicate --help` to list every command and whether it is supported.
